**1. 研究问题是什么**

输入是一幅高光谱图像，每个像素有多个连续光谱波段；只有少量像素带地物类别标签。目标是学习一个分类器，为其余像素预测类别。

可以用农田旁边的一条道路理解：单看目标像素的光谱，可能与屋顶等材料相近；观察空间邻域有助于判断它处在道路还是建筑区域。与此同时，连续波段中的局部曲线变化也是区分材料的重要线索。

作者关心如何同时利用三种关系：

1. 目标像素与周围像素的空间关系。
2. 相邻光谱波段之间的局部相关性。
3. 当前输入序列中较远位置之间的相关性。

注意力可以直接连接序列中任意两个位置，但不会自动优先尊重空间邻接；图卷积可以显式限定邻居，但单层传播的范围有限。论文把二者组合，给模型同时提供灵活的关系建模能力和局部结构约束。

这并不意味着 Transformer 在数学上不能学习局部关系。更准确的说法是：局部关系不是普通全连接注意力必然学到的偏好，图卷积为它加入了明确的结构先验。

**2. 为什么重要**

高光谱标注通常需要地面调查或专家判断。有限标注下，模型如果需要自行学会全部空间、光谱规律，容易受样本不足影响。预先把适当的局部结构放进模型，可以减少需要从标签中学习的自由度。

边界像素也值得单独处理。如果常规窗口以目标为中心，图像边缘会出现越界位置，需要补零或镜像。本文的 follow patch 直接把整个窗口移回图像内，尽量使用实际观测像素。

与导师项目的联系是：本文提供一种同时利用空间和光谱结构的分类骨架，并关注计算量。但空间一致性不等于噪声鲁棒性的充分证明，低于若干基线的 FLOPs 也不等于已经完成模型压缩和端侧部署。

**3. 作者如何解决**

图 1 位于第 5 页，可以按以下顺序理解：

```text
目标像素及其坐标
        ↓
Follow patch：取一个真实的局部窗口，越界时整体平移
        ↓
Patchwise spectral embedding：融合邻近光谱通道并保留原特征
        ↓
映射为 token 特征
        ↓
Graphormer Encoder
  自注意力：当前序列中所有位置建立联系
  图残差块：沿给定局部图聚合信息
  归一化、MLP、残差：变换与保留特征
        ↓
输出目标像素的各类别分数
        ↓
仅在训练标签上计算交叉熵
```

**Follow patch 的重点是移动窗口。** 它不是 SLIC 超像素，也不是把规则窗口内所有像素预先压成一个均值节点。靠近图像边缘时，目标像素可能不在窗口中心，必须保留它在窗口内的真实位置。

**光谱嵌入的重点是邻近通道融合。** 不只观察单个波段，而是让其邻近波段参与特征构造，再保留原通道信息。它有助于表达局部光谱形态，但本身不是经过证明的去噪算子。

**Graphormer 的重点是全连接关系与局部关系配合。** 注意力允许远一些的 token 互相影响，图卷积对给定图上的邻接关系进行聚合。这里的“全局”应相对于送入注意力的序列理解；不能自动解释为一次关注整幅遥感图像。

公开入口每个样本是一个 9×9 窗口，将其中 81 个像素展开为 81 个 token。各窗口属于不同 batch 样本，不会因为放进同一 batch 就互相做注意力。论文对 patch 和 token 的记号不够一致，以下推导明确采用这套空间 token 解释，图残差部分则按论文公式说明。

**4. 核心公式推导**

本节目标是建立“局部窗口 → 表示 → 类别概率 → 交叉熵”的可检查计算链。符号统一为：图像 H×W×B，窗口边长 m，窗口 token 数 n=m²，特征维度 d，注意力头数 h，每头维度 d_h，类别数 C。B 是波段数，不是 batch 大小；图邻接记为 A，注意力权重记为 S，避免混用。

**4.1 Follow patch 的坐标推导，对应式 (5)–(8)**

使用从 0 开始的行列坐标。目标像素是 (r,c)，窗口边长 m 为奇数，且 H,W≥m。令半径 a=(m−1)/2。

没有边界时，窗口左上角是 (r−a,c−a)。为保持完整 m×m 窗口，需要满足：

$$0\le r_0\le H-m,\qquad 0\le c_0\le W-m.$$

将理想左上角截断到合法区间：

$$r_0=\operatorname{clip}(r-a,0,H-m),\qquad
c_0=\operatorname{clip}(c-a,0,W-m).$$

得到输入：

$$P=I[r_0:r_0+m,\ c_0:c_0+m,\ :].$$

这里是 Python 式左闭右开切片。窗口展平后，目标位置为：

$$t=(r-r_0)m+(c-c_0).$$

这是一个索引恒等关系，不是模型学习的参数。对于 5×5 图像、3×3 窗口，左上角目标 (0,0) 的窗口为前 3 行、前 3 列，目标 token 为 0；右下角目标 (4,4) 的窗口起点是 (2,2)，目标 token 为 8。图像内部真正位于窗口中心时，目标索引才是 (m²−1)/2。

同一个边缘窗口可能服务于多个目标像素，它们的输入窗口相同，但目标 token 不同。因此不能统一取中心 token，也不能不加说明地改用整个窗口的平均池化。

原文式 (5)–(6) 的边缘起点写成 W−m−1、H−m−1；与其右下角及窗口大小约定合用时存在一位偏差，式 (6) 的条件还混用了 x、y。上述 clip 公式是按固定窗口大小整理的修正版，与 `functions.py` 使用的 `W-patch:W`、`H-patch:H` 一致。

**4.2 邻域光谱嵌入，对应式 (9)–(14)**

暂时把 X_i 理解为窗口内第 i 个波段的 m×m 特征图。取奇数 k 个邻近波段，令：

$$s_i=\operatorname{clip}\left(i-\frac{k-1}{2},0,B-k\right),$$

$$X^{i}_{\mathrm{group}}=
\operatorname{Concat}(X_{s_i},\ldots,X_{s_i+k-1}).$$

原文式 (10) 的尾端索引也有类似偏移疑点。这里明确采用合法长度为 k 的窗口，避免把印刷记号直接复制成越界代码。

学习一个映射，把 k 个通道融合回一个通道：

$$X_i'=W_iX^i_{\mathrm{group}}+b_i,\qquad
X_i''=X_i'+X_i.$$

对某个空间位置 p 来说，可以写成：

$$x_i''(p)=x_i(p)+\sum_{j=0}^{k-1}w_{ij}x_{s_i+j}(p)+b_i.$$

例如 k=3、三个权重均为 1/3 时，新增项就是三个邻近通道的均值。但真实权重由训练学习，可以为负，也不要求和为 1，所以它还可以表达某些差分特征，不能一概称为平滑滤波。

将各通道拼接，再进行归一化和激活：

$$F=\operatorname{Concat}(X_0'',\ldots,X_{B-1}''),\qquad
F'=\operatorname{ReLU}(\operatorname{BN}(F)).$$

标准 BN 的归一化部分为：

$$\operatorname{BN}(u)=\gamma\frac{u-\mu}{\sqrt{v+\epsilon}}+\beta.$$

这里 v 是方差。论文式 (14) 分母直接写 σ，而文字称 σ 为方差；复现时应核对实际归一化定义，不能把除以方差当作标准 BN。

残差相加保留原特征路径，其机制解释是让网络学习“在原有特征上增加什么修正”；这不等于证明噪声必然减少。

另一个需要区分的概念：公开入口先做 PCA。如果在 PCA 后的通道轴上取邻域，相邻通道是相邻主成分，并不再对应相邻物理波长。论文的光谱邻近性解释与这类预处理之间，需要单独对齐。

**4.3 Token 嵌入与自注意力，对应式 (3)–(4)、(15)–(16)**

将窗口展平为 n×B，每个像素的光谱向量经过线性映射和位置编码得到 U∈ℝ^(n×d)：

$$u_i=x_iW_E+e_i.$$

位置编码 e_i 告诉模型 token 在窗口内的位置。公开入口使用可学习位置编码，且没有启用额外的 CLS token。

对一个注意力头：

$$Q=UW_Q,\qquad K=UW_K,\qquad V=UW_V.$$

第 i 个位置对第 j 个位置的打分为：

$$a_{ij}=\frac{q_i^Tk_j}{\sqrt{d_h}},\qquad
S_{ij}=\frac{\exp(a_{ij})}{\sum_{u=1}^{n}\exp(a_{iu})}.$$

于是：

$$y_i=\sum_jS_{ij}v_j,\qquad
Y=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_h}}\right)V.$$

含义是“先决定参考谁，再对参考信息加权”。softmax 按行计算，故每个节点的参考权重和为 1。教学例子中若一行分数是 [2,1,0]，权重约为 [0.6652,0.2447,0.0900]。

为什么除以 √d_h？在 q、k 各分量独立、零均值、单位方差且彼此独立的简化假设下：

$$\operatorname{Var}(q^Tk)=\operatorname{Var}\left(\sum_{j=1}^{d_h}q_jk_j\right)=d_h.$$

所以缩放后方差变为 1。这是解释数值尺度的条件性推导，不是声称训练后的分量永远满足这些独立分布假设。

多头就是用不同投影重复这个过程，再拼接并映射：

$$\operatorname{MHSA}(U)=\operatorname{Concat}(Y_1,\ldots,Y_h)W_O.$$

常见设计取 d_h=d/h，但这不是必须条件。当前入口 d=200、h=4，而 `dim_head` 默认 16：内部拼接维度是 64，再映射回 200。不能看到四个头就断言每头一定是 50 维。

**4.4 图卷积与图残差，对应式 (17)–(18)**

论文用给定图上的聚合细化注意力输出：

$$Y'=\operatorname{GELU}(\bar AYW_G).$$

展开第 i 个节点：

$$y_i'=\operatorname{GELU}\left(\sum_j\bar A_{ij}y_jW_G\right).$$

与注意力相比，这里由图矩阵指定允许哪些节点参与，以及相应的权重。它为局部结构增加约束，并不意味着注意力不能连接邻居。

原文式 (18) 继续执行一次图传播并设置旁路：

$$Y''=\operatorname{MLP}_{g}\left(\operatorname{GELU}(\bar AY'W_G)\right)
+\operatorname{MLP}_{s}(Y).$$

这里给两个 MLP 加下标用于区分路径；原文重复使用 W_G、MLP，是否共享参数需要依据实际实现确认。图 4 还包含 LayerNorm、注意力残差和额外 MLP，公式没有把所有细节展开，不能把两条式子当作完整可运行网络定义。

为理解两层局部传播，考虑一个明确的简化：去掉激活、将两条 MLP 看作恒等映射，假设两层权重分别是 W_1、W_2，则：

$$Y''=\bar A^2YW_1W_2+Y.$$

其中 (Ā²)_ij=Σ_k Ā_ik Ā_kj，表示经过中间节点 k 的两步路径。因此两次图传播可以覆盖局部图的两跳邻域。这只是线性化的机制说明，不能取代原网络；输入 Y 已经过注意力，也不能据此说整个网络的感受野只有两跳。

原文没有充分交代 Ā 的构造与归一化。公开预处理生成窗口内 3×3 空间邻域的高斯边权：

$$A_{ij}=\mathbf1[j\in\mathcal N_{3\times3}(i),j\ne i]
\exp\left(-\frac{\|x_i-x_j\|^2}{\sigma^2}\right),\qquad \sigma=10.$$

但是当前主入口没有把该 A 传入图卷积，不能据此认定这就是论文实验采用的完整图算子。

**4.5 从特征到类别，对应式 (19)**

令模型为目标像素生成 C 维 logits z。转换为类别概率：

$$p_c=\frac{e^{z_c}}{\sum_{u=1}^{C}e^{z_u}}.$$

若真实类别为 y，单个样本的负对数似然是：

$$\ell=-\log p_y=-z_y+\log\sum_ue^{z_u}.$$

训练集为 T，交叉熵可写成：

$$\mathcal L=-\frac1{|T|}\sum_{i\in T}\sum_{c=1}^{C}y_{ic}\log p_{ic}.$$

这是将论文的求和损失写成常用样本均值形式，缩放方式要在配置中说明。对单个样本求导：

$$\frac{\partial\ell}{\partial z_c}=p_c-\mathbf1[c=y].$$

例如正确类别是第 2 类，模型输出 [0.2,0.3,0.5]，则梯度是 [0.2,−0.7,0.5]，梯度下降会提高正确类别分数、降低另外两类分数。

这与 AHSGC 的关键区别是：AHSGC 用自身预测构造软目标；这里的训练目标来自真实标注。最终直接 argmax 得到类别，不再做 K-means 或 Hungarian 聚类标签匹配。

**4.6 复杂度应该怎样理解**

令 n 是一次注意力序列的 token 数，不与窗口边长 m 混用。注意力矩阵计算和作用于 V 的主要代价是 O(n²d_h) 每头，投影还产生 O(nd²) 量级的开销。

稀疏图传播通常涉及 O(|E|d+nd²)；如果用稠密邻接相乘，则会有 O(n²d) 项。是否稀疏实现直接影响实际代价。

对于当前空间 token 路径，n=m²，因此注意力矩阵的元素数是 m⁴。9×9 窗口有 81 个 token、每头 6561 个关系；11×11 窗口有 121 个 token、每头 14641 个关系，约增加到 2.23 倍。

所以不能脱离 token 定义说“大窗口一定减少计算量”。全文中 P_n 有时指 patch 数、有时指 patch 尺寸，应该重新区分后再分析。网络还要为多个目标像素处理多个窗口，单次前向 FLOPs 不等同于整幅图的总分类开销。

**5. 数据处理流程**

先以公开入口的 Indian Pines 为例追踪实际形状：

| 阶段 | 公开代码行为 | 典型输出 |
| --- | --- | --- |
| 读取 | 读取 corrected 图像与 GT，剔除标签 0 的位置 | 图像及有效像素坐标 |
| 划分 | 每类随机选 30 个；总样本≤60 的类选 15 个 | 训练与测试坐标、标签 |
| PCA | 对整幅图拟合 PCA，`whiten=True`，默认 70 维 | H×W×70 |
| 标准化 | 对整幅 PCA 图按通道 StandardScaler | H×W×70 |
| Follow patch | 为每个目标提取 9×9 窗口，保存实际目标索引 | 样本数×9×9×70 |
| 展平 | 空间位置作为 token | 样本数×81×70 |
| 线性嵌入 | `Linear(70,200)`，加位置编码 | batch×81×200 |
| 注意力 | 4 头，每头维度 16 | 注意力权重 batch×4×81×81 |
| 分类头 | 为每个 token 输出 16 类分数 | batch×81×16 |
| 目标读出 | 按 `center_pos` 取真正目标位置 | batch×16 |

表中是能沿当前入口确认的数据流，不包含没有被调用的论文模块。`center_pos` 虽然名字带 center，实际存的是目标像素在窗口中的位置，边界样本未必是中间位置。

此入口使用整幅图的无标签特征拟合 PCA 和标准化统计。它没有直接把测试标签当作 PCA 输入，但使用了测试区域的特征分布。复现必须说明是允许整幅图无标签特征的同场景协议，还是严格只在训练区域拟合变换的协议。

程序一次性创建训练、测试及全部有效像素的窗口，存在重复存储和较高显存占用。小批次训练不意味着预处理只保留一个小批次。工程上可考虑按需提取窗口，但那是后续实现调整。

常用数据版本可从 [GIC 高光谱数据页](https://www.ehu.eus/ccwintco/index.php?title=Hyperspectral_Remote_Sensing_Scenes)核对 Indian Pines、Salinas；Houston 2013 应对照 [IEEE GRSS 数据说明](https://www.grss-ieee.org/community/technical-committees/2013-ieee-grss-data-fusion-contest/)。不要把 Houston 2013 和 Houston 2018 当成同一数据集。本文的随机少量标注协议也不应默认等同于竞赛官方固定训练测试划分。

**6. 实验设计逻辑**

**6.1 主实验比较什么**

三个数据集是 Indian Pines（IP）、Salinas、Houston 2013（UH2013）。对比 2-D CNN、CRNN、miniGCN、S²GCN、GLGAT-CFSL、L2GTE、SpectralFormer（SF）和 SSFTT，覆盖卷积、图网络和 Transformer。

论文表 I 的训练样本数为：IP 大多数类 30 个，小类第 1、7、9 类各 15 个，总计 435；Salinas 16 类各 30 个，总计 480；UH2013 15 类各 30 个，总计 450。IP 的 Oats 类只有 20 个标注像素，取 15 个训练后只剩 5 个测试样本，所以小类的 100% 需要结合分母理解。

这是一组按类固定数量的主实验，不是“三个数据集统一用 1% 标签”。第 11–12 页另做 0.25%–3% 标签比例变化实验，两者要分开。

表 II 三个数据集都设置为：200 个 epoch，9×9 窗口，学习率 5×10⁻⁴，编码器深度 3，注意力头数 4。论文说明重复实验 10 次，主表以均值±波动值形式呈现；复现时应明确并报告所使用的标准差定义与每次划分。

表 III–V 中的总体准确率 OA：

| 数据集 | S²GFormer | 表中 OA 最高的对比方法 | OA 差值 |
| --- | ---: | --- | ---: |
| IP | 93.55±0.47% | L2GTE：90.38±1.30% | +3.17 个百分点 |
| Salinas | 96.92±0.36% | L2GTE：92.26±0.73% | +4.66 个百分点 |
| UH2013 | 94.12±0.87% | GLGAT-CFSL：89.92±0.76% | +4.20 个百分点 |

UH2013 正文把 S²GCN 的 89.31% 当作次优值，得出 4.81 的提升；但表中 GLGAT-CFSL 为 89.92%。此处按数值大小计算，不照抄加粗、下划线或叙述。

对应的 S²GFormer AA 是 96.56±0.35%、98.23±0.07%、95.07±0.55%。OA 按像素数量加权，AA 对各类别准确率取均值，因此后者更能提醒读者观察小类别。

**6.2 消融实验验证什么**

第 12–13 页定义四个变体：

| 变体 | 操作 | 要验证的问题 |
| --- | --- | --- |
| V1 | 去掉像素到区域的变换模块 | 局部窗口组织是否有用 |
| V2 | 将光谱嵌入替换为均值操作 | 学习邻域融合是否优于简单平均 |
| V3 | 用普通 Transformer 替换 Graphormer | 图结构处理是否提供额外收益 |
| V4 | 移除 Graphormer 的残差块 | 残差设计是否有贡献 |

图 13(a) 的柱顶给出了数值，换算成 OA 百分比为：

| 数据集 | 完整模型 | V1 | V2 | V3 | V4 |
| --- | ---: | ---: | ---: | ---: | ---: |
| IP | 93.55 | 88.71 | 91.64 | 86.37 | 92.18 |
| Salinas | 96.92 | 91.29 | 95.15 | 92.73 | 94.70 |
| UH2013 | 94.12 | 88.28 | 93.67 | 90.24 | 93.05 |

例如 IP 上，普通 Transformer 替换 Graphormer 后，OA 从 93.55% 降至 86.37%，支持这组设置下结构设计的作用。不过，严格比较还应核对替代模块的输入维度、参数量、训练预算和验证方式是否相同；图中这些点值本身不能代替显著性检验。

表 VI 进一步比较把图残差加入不同编码层。全加入时 IP 为 93.55，与主表一致；Salinas 和 UH2013 列则分别写 95.62、94.66，与主表 OA 的 96.92、94.12 不一致。这些数值恰好与主表相应 Kappa 数字一致，可能存在标注或转录问题，但没有原始结果不能擅自更正。

**6.3 时间和 FLOPs 能支持什么**

表 VII 只列 SF、SSFTT、S²GFormer 三种方法的效率比较，其中 FLOPs 分别为 1.50 G、2.59 G、1.09 G。S²GFormer 在这两项对比中较低，并不等于它比全部方法都轻。

运行时间表在每个数据集下列两列数值，但表头没有清楚标出单位和两列各自含义；正文提到训练、测试时间，复现时仍应核准其计时范围。不要把它直接换算成端侧 FPS，也不要混同单窗口前向与全图推理。

**6.4 一个必须核对的指标一致性问题**

表 V 给出 UH2013 的 OA=94.12%、Kappa=94.66（按百分比量级呈现）。标准 Cohen's kappa 定义是：

$$\kappa=\frac{p_o-p_e}{1-p_e},\qquad p_o=\mathrm{OA}.$$

在 0≤p_e<1 的正常定义下：

$$\kappa-p_o=\frac{p_e(p_o-1)}{1-p_e}\le0.$$

因此同一预测结果的 κ 不应高于 OA，逐次运行满足的关系在均值上也成立。此处应标记为需要作者原始混淆矩阵核对的表格不一致，不能把 94.66 当成已确认的有效 Kappa，更不能据此推断作者意图。图 13(c) 的 UH2013 完整模型又标为 0.9471，与表 V 的 0.9466 不同，也仍高于对应 OA。

**7. 创新点**

合理的创新总结包含三部分。

**输入组织方面**：通过 follow patch 将越界窗口整体移回图内，为边缘目标保留真实空间上下文；目标位置随窗口变化而更新。

**光谱表示方面**：通过邻近波段的可学习融合和残差，提取局部光谱模式，避免仅用区域均值表示复杂光谱特征。

**关系建模方面**：在 Transformer 编码器中加入图残差处理，让注意力与显式邻接关系共同作用于特征。

不能把它概括为“首次提出注意力”“首次提出图卷积”或“第一次把图与 Transformer 结合”。论文引言本身已列出图与 Transformer 相关工作，其贡献更适合落在高光谱分类的具体模块设计与组合上。

对于新生，最有价值的研究思路是：先明确某个模块缺少什么信息，再引入与之互补的机制，并用受控消融判断新增部分是否真正有用。

**8. 局限性**

**8.1 有监督场景的边界**

本文需要真实训练标签，不能直接解决完全无标签的聚类任务。同一场景里随机选少量标签，也不同于跨地区、跨传感器、跨时相的少样本迁移。

**8.2 局部窗口可能混入其他类别**

窗口平移保证取到真实像素，但不会保证窗口内都是同一地物。边界附近可能同时包含道路、农田和建筑。目标位置不能丢失，窗口越大也不保证越好。

**8.3 随机像素划分下存在空间相关性**

训练和测试的中心像素可以不同，但它们的 9×9 窗口仍可能高度重叠。模型可能在训练上下文中见过测试中心的无标签特征。它不自动等于把测试标签用于训练，却限制了结论：同场景随机像素结果不能直接当作空间独立区域上的泛化能力。可另外报告按区域划分、带缓冲带的实验。

**8.4 噪声与轻量化的证据有限**

论文通过真实场景性能和空间结果图讨论干扰，但没有系统的高斯、脉冲、条带等噪声强度实验，也没有量化或蒸馏实验。FLOPs 表也不足以证明目标设备上的时延、内存或功耗。

**8.5 论文描述、配置和公开入口之间存在差距**

图 1 及正文称四个编码块，表 II 和表 VI 使用三个，当前入口设置五层；公开入口也没有把核心图残差与邻域光谱卷积接入调用路径。这会影响结构和结果复现。

**8.6 公开入口使用测试集选择结果**

`Main` 第 118–125 行在 `label_test_loader` 上计算 OA，并保留最高 OA 对应的指标。按这段代码执行，相当于根据测试表现选择报告结果，而不是仅在最终冻结模型后测试。这会使报告偏向该测试集；正确的复现实验应另设验证集，或预先固定最终 epoch。此结论针对当前公开入口，不能直接证明论文实验的内部运行细节。

**9.3 从 Indian Pines 建立一个最小可审查实验**

先使用 IP，按表 I 选 435 个训练像素，固定并保存坐标。第 1、7、9 类各 15 个，其余各 30 个。数据路径在 `functions.py` 中硬编码为 `/home/tsing/data/datasets/`，应改为明确的数据目录配置；同时确认 MAT 键名和类别映射。

对最小数据流，应能打印出：

```text
原始图像 H×W×B
→ PCA/标准化 H×W×70（若采用公开入口设置）
→ 单窗口 9×9×70
→ batch×81×70
→ 嵌入 batch×81×200
→ 每头关系 batch×4×81×81
→ 所有 token logits batch×81×16
→ 目标 logits batch×16
```

这条数据流首先验证目标像素、标签、坐标和模型输出是否对应。之后再恢复论文模块，而不是一开始就追求表中的 93.55%。

**9.4 分阶段恢复论文设计**

1. 跑通 Follow patch 加普通 Transformer 的分类基线，验证边缘目标的位置没有取错。
2. 接入光谱邻域残差嵌入，明确它处理的是原始波段还是 PCA 通道。
3. 明确 A 的邻域、边权、对称性、自环及度归一化，在实际 forward 路径中接入图残差。
4. 用模块 hook 或梯度检查确认两个新增模块真的执行，并影响 logits。
5. 对照表 II 设置 3 层、4 头、200 epoch、学习率 5×10⁻⁴、窗口 9×9；其余设置保留在配置中。
6. 在固定数据划分上进行有针对性的模块消融，再扩展到多种子和另外两个场景。

这会形成依据论文重建的实现。若尚未取得与论文实验一致的完整版本，应如实保留这个身份，不能悄悄把自己的补全称作作者原版。

图结构的归一化尤其要明确。例如常见的 D̃^−1/2(A+I)D̃^−1/2 与当前未调用 GCN 类中的 I+D^−1/2AD^−1/2 不相同，不能因为都带自环就当作同一算子。

**9.5 统一训练与评估协议**

每个 run 都重新指定种子并生成或加载对应划分，不能只在循环外设一次种子。论文固定标签预算很小，验证数据应从允许的开发数据预算中安排并披露，或使用提前固定的训练轮数；不能为了验证随意增加额外标注还继续宣称相同标签预算。

模型选择只使用验证集，最后冻结模型后再评估测试集。以混淆矩阵统一计算 OA、AA、逐类准确率和 Kappa，并检查 κ≤OA 的基本关系。没有聚类标签置换，所以不使用 Hungarian 匹配。

保留两种明确区分的协议也有价值：一种匹配原论文的同场景随机像素设置；另一种使用空间独立区域，评价更严格的泛化。后者的分数不能与原表直接比较后宣称复现失败。

**9.6 先处理工程阻塞，再测效率**

静态代码中可见的执行问题包括：硬编码数据路径、模型未整体移到输入设备、强制 CUDA 分配、评价未使用 `no_grad`、所有窗口预先常驻设备、以及构建了最终未参与预测的图和位置编码。训练前应按实际环境逐项修正，并记录与原快照的差异。

依赖可以从导入识别为 PyTorch、NumPy、SciPy、scikit-learn、einops 等，但仓库没有足以锁定原论文环境的依赖清单。应保存成功运行时的版本，不要把旧 `.pyc` 当作环境说明。

效率测量分开记录 PCA、窗口提取、建图、训练、单窗口前向、整图预测的时间，注明 batch 大小、硬件、精度类型、是否同步 GPU，并记录峰值内存。按需提取窗口与缓存策略会影响实际部署成本。

**9.7 与导师项目衔接**

基线稳定后，可分别检验三类问题：光谱邻域模块能否抵抗可控噪声；图残差在噪声破坏边权后是否仍有帮助；压缩 embedding、减少头数或层数后，精度、时延、显存怎样变化。把这些问题分开做受控实验，才能判断性能来自结构、噪声处理还是单纯模型容量。
